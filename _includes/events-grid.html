{%- comment -%} Pop-up schedule. Only upcoming events go in the grid: an event whose end date had passed when the site was built isn't shown there (and, on the homepage, isn't shown at all). assets/js/site.js also hides any that pass between builds. With archive=true (the /events/ page) the past ones are listed below the grid under "Past pop-ups", clearly marked as past, so the history stays readable without looking current.
